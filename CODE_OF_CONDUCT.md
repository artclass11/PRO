# Contributor Covenant Code of Conduct

We are committed to a welcoming, respectful, and harassment-free community.

Participants should communicate professionally, focus feedback on the work, and assume good intent. Harassment, discrimination, threats, personal attacks, and deliberate disruption are not acceptable.

Project maintainers may remove content, close discussions, or take other reasonable action when community standards are violated.

For security concerns, use the private reporting path described in SECURITY.md.
