# Security Policy

## Supported versions

Only the latest release on the default branch is actively supported.

## Reporting a vulnerability

Do not open a public GitHub issue for suspected security vulnerabilities. Use GitHub private vulnerability reporting for this repository when available. Include reproduction steps, affected files, impact, and mitigation ideas.

Never include API keys, passwords, tokens, private customer data, or other secrets in an issue or pull request.

## Security posture

ShadowPilot is a policy/control layer, not a full sandbox. Adapter implementations are part of the trusted computing base. Receipt hashes provide tamper evidence, not non-repudiation.
