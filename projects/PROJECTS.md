## Release gate

A day is complete only when:
1. The project runs from a clean checkout.
2. Core behavior has automated tests.
3. CI configuration is present.
4. README includes problem, setup, usage, scope, and license.
5. Secrets are not committed.
6. The change is committed and publicly visible.
7. The row above is changed to DONE and the next day becomes NEXT.
